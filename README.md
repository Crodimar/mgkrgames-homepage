# MGKR Games Homepage

A polished, responsive static homepage for **mgkrgames.com**.

## Files

- `index.html` — page structure and content
- `styles.css` — complete responsive design
- `script.js` — mobile menu, scroll header and reveal animations
- `favicon.svg` — MGKR favicon

## Preview locally

Open `index.html` directly in a browser, or run a local server:

```bash
python3 -m http.server 8080
```

Then visit:

```text
http://localhost:8080
```

## Publish

Upload all four files to your hosting provider's public folder.

Common options:

- Cloudflare Pages
- Netlify
- Vercel
- GitHub Pages
- Any normal web hosting account

## Important edits

Search and replace these values before publishing:

- `https://smash.mgkrgames.com`
- `hello@mgkrgames.com`
- Game descriptions and development updates

## Structure

- Sticky header and mobile navigation
- Hero section
- Smash Arena feature
- Games section
- About section
- Development updates
- Contact call-to-action
- Footer

No JavaScript framework or build process is required.
